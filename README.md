# SparklingTime
A countdown timer with an animated hourglass and a productivity quote when time's up. Built with HTML, CSS and JavaScript.

**Main Features**
Three pages
**Set the time:** choose minutes and seconds, then press Start.
**Hourglass:** watch the sand fall, with small + and − buttons to add or remove 1 minute.
**Quote:** when time is up, a productivity quote appears for a few seconds, then you're taken back to the start.


**How to run it**

No setup needed.
Download or clone this repository.
Double-click SparklingTime.html to open it in your browser.

That's it!
